Building it in egui

  • Two Visuals built from the table, with ThemePreference::System so the app follows the OS appearance.
  • On Mac, use with_fullsize_content_view and a transparent title bar for the unified toolbar. Windows and Linux keep native title bars.
  • egui can’t turn on tabular figures, so lay out countdown digits in fixed-width cells to stop the time from jittering.
  • The ring is a PathShape arc sampled every few degrees. Settings is a second viewport opened with ⌘,.
  • The menu bar item uses tray-icon with a native muda menu, which follows light and dark by itself.
